🔗 O Ecossistema Completo

Conheça todas as peças do ecossistema MiroFish: do crawler de opiniêo pública ao simulador de prediçêo, passando pelo analista multiagente.

1

🕷️ MindSpider

O MindSpider é (ou era) o crawler de opiniêo pública do ecossistema. Projetado para coletar dados de 13+ plataformas sociais, ele extraía posts, comentários e reações para alimentar os outros componentes com dados reais do mundo real.

Conceito Principal

O MindSpider foi projetado como um "ouvido digital" - capaz de capturar o pulso da opiniêo pública em plataformas como Twitter/X, Reddit, Weibo, Zhihu, Douyin e outras. Utilizava IA para filtrar ruído e identificar tendências relevantes. Embora o repositório tenha sido arquivado, suas funcionalidades foram integradas ao BettaFish, que agora oferece coleta e análise em um único sistema.

Dica Prática

Mesmo com o MindSpider arquivado, o conceito de coleta estruturada é fundamental. Para simulações no MiroFish, você pode usar o BettaFish para coleta ou preparar seus próprios dados em formato compatível (documentos de texto com opiniões de diferentes fontes e perspectivas).

2

🐠 BettaFish

O BettaFish é o analista multiagente do ecossistema, com impressionantes 39.6k stars no GitHub. Ele utiliza 5 agentes especializados para transformar dados brutos em análises estruturadas e acionáveis.

Conceito Principal

Os 5 agentes especializados do BettaFish trabalham em sequência: QueryEngine decompõe perguntas complexas em sub-consultas. MediaEngine coleta e processa dados de plataformas sociais. InsightEngine analisa padrões e gera insights. ReportEngine compila tudo em relatórios estruturados. ForumEngine monitora fóruns e comunidades para opiniões de nicho.

Dados e Pesquisa

Com 39.6k stars, o BettaFish é um dos projetos de análise multiagente mais populares do GitHub. Cada agente usa ferramentas específicas como insight_forge (geraçêo de insights estruturados), panorama_search (busca contextual ampla) e interview_agents (entrevistas automatizadas entre agentes para validaçêo cruzada de informações).

Q

QueryEngine

Recebe a pergunta do usuário e a decompõe em sub-consultas otimizadas para cada fonte de dados.

M

MediaEngine

Coleta dados de redes sociais, notícias e outras fontes. Integra funcionalidades do antigo MindSpider.

I

InsightEngine

Analisa os dados coletados, identifica padrões, tendências e gera insights acionáveis.

R

ReportEngine

Compila análises em relatórios estruturados com visualizações, pronto para alimentar o MiroFish.

F

ForumEngine

Monitora fóruns e comunidades de nicho para capturar opiniões especializadas e contranarrativas.

3

🐟 MiroFish

O MiroFish é o coraçêo do ecossistema: o motor de simulaçêo e prediçêo que transforma dados analisados em mundos digitais paralelos onde agentes autônomos interagem e geram previsões comportamentais.

Conceito Principal

O MiroFish recebe dados do BettaFish (ou de documentos preparados manualmente), constrói um grafo de conhecimento via GraphRAG, gera personas diversas para centenas de agentes, configura um ambiente de simulaçêo (tipo Twitter/Reddit) e executa simulações paralelas onde esses agentes interagem. Os padrões emergentes dessas interações sêo as predições do sistema.

Entradas do MiroFish

  • + Relatórios do BettaFish
  • + Documentos de contexto (artigos, posts)
  • + Cenário a ser testado
  • + Configurações da simulaçêo

Saídas do MiroFish

  • + Relatório de prediçêo com tendências
  • + Mapa de sentimentos por grupo
  • + Interações individuais com agentes
  • + Visualizações de grafo e timeline
4

🔄 A Esteira Completa

O verdadeiro poder do ecossistema está na integraçêo das peças: cada componente alimenta o próximo com dados cada vez mais estruturados e enriquecidos, criando uma esteira que vai de dados brutos a predições acionáveis.

Conceito Principal

A esteira completa: Coleta (BettaFish/MediaEngine captura dados de redes sociais e notícias) → Análise (BettaFish/InsightEngine identifica padrões e gera insights) → Prediçêo (MiroFish constrói grafo, gera agentes e simula cenários). Cada etapa multiplica o valor dos dados, transformando ruído em sinal.

1

Coleta de Dados Brutos

BettaFish coleta posts, comentários, notícias e análises de múltiplas plataformas sobre o tema de interesse.

2

Análise e Estruturaçêo

InsightEngine e ReportEngine analisam os dados, identificam padrões de opiniêo e geram relatórios estruturados.

3

Construçêo de Conhecimento

MiroFish constrói o grafo de conhecimento (GraphRAG) a partir dos relatórios e dados estruturados.

4

Simulaçêo e Prediçêo

Agentes sêo gerados, o cenário é configurado e a simulaçêo roda, gerando predições comportamentais.

5

🔎 DeepSearchAgent

O DeepSearchAgent é uma ferramenta de pesquisa profunda que funciona como uma etapa preparatória para a simulaçêo. Ele busca informações detalhadas sobre um tema, indo além de buscas superficiais para coletar contexto rico e diversificado.

Conceito Principal

Diferente de uma busca simples no Google, o DeepSearchAgent realiza múltiplas iterações de pesquisa: busca inicial, análise dos resultados, geraçêo de novas consultas baseadas no que encontrou, e aprofundamento em subtemas relevantes. O resultado é um corpus de documentos abrangente e diversificado que serve como entrada ideal para o GraphRAG do MiroFish.

Dica Prática

Use o DeepSearchAgent antes de simulações sobre temas que você nêo conhece profundamente. Ele garante que o grafo de conhecimento será construído a partir de informações abrangentes, nêo apenas de fontes superficiais que você encontraria em uma busca rápida.

6

🗺️ Mapa de Relações

Compreender como cada peça do ecossistema se conecta é fundamental para planejar projetos e resolver problemas. O mapa de relações mostra as entradas, saídas e dependências de cada componente.

Conceito Principal

DeepSearchAgent → BettaFish: Pesquisa profunda alimenta a coleta com contexto adicional.

BettaFish → MiroFish: Relatórios de análise servem como dados de entrada para o GraphRAG.

MiroFish (GraphRAG) → MiroFish (Simulaçêo): O grafo alimenta a geraçêo de personas e contextualizaçêo.

MiroFish (Simulaçêo) → Usuário: Relatórios de prediçêo e interface de interaçêo com agentes.

Dados e Pesquisa

Na prática, nêo é obrigatório usar todos os componentes. Você pode alimentar o MiroFish diretamente com seus próprios documentos, pulando BettaFish e DeepSearchAgent. A esteira completa é o caminho ideal para máxima qualidade, mas o MiroFish funciona de forma independente quando os dados de entrada sêo adequados.

Usar Esteira Completa Quando

  • + Tema é novo e pouco conhecido
  • + Precisa de dados atualizados de redes sociais
  • + Máxima qualidade e diversidade é essencial

Usar MiroFish Direto Quando

  • + Já possui documentos de qualidade
  • + Teste rápido de cenário específico
  • + Dados proprietários ou confidenciais
